# REPO_Українізатор
Мод для R.E.P.O., який перекладає гру на українську мову.


## Ось як встановити мод:

- Встановіть [BepInEx](https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/)
- Розпакуйте цей мод у вашу папку `REPO/BepInEx`.

Або, зручніше, скористайтеся менеджером модів Thunderstore для автоматизації процесу встановлення.
